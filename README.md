# Shubham Sah Productions

Static HTML and CSS website for a wedding cinematography, photography, and music production studio.

## Pages

- `index.html` — home
- `about.html` — story, team, why us
- `services.html` — video, photography, music
- `portfolio.html` — filterable gallery
- `testimonials.html`
- `contact.html`
- `faq.html`
- `privacy.html`

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Social links, phone, and address are placeholders — replace them with live profiles before publishing.
